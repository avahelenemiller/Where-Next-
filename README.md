# Where-Next-

About the Project

Where Next? is a Python application that recommends holiday destinations based on users' personal preferences. It aims to make choosing a holiday easier by matching users with destinations that suit their budget, preferred climate, holiday style and interests.

How It Works

Users select their preferences, and the application compares them against a list of destinations. Each matching preference receives a point, and the destination with the highest score is recommended.

Technologies Used

Python: application and matching system.

Streamlit: interactive website interface.

Visual Studio Code: coding environment.

How to Run

- Download the project files.

- Open the project folder in Visual Studio Code.

- Install Streamlit using pip install streamlit.

- Run streamlit run app.py in the terminal.
