# Where-Next-
About the Project
Where Next? is a Python application designed to help users find their ideal holiday destination based on their personal preferences.

Why I Created It
I created this application to make choosing a holiday destination easier. With so many destinations available, it can be difficult to decide where to travel. Where Next? simplifies this process by matching users with destinations that suit their preferences.

How It Works
Users select their:
- Budget
- Preferred climate
- Holiday style
- Activities 
The application then compares these preferences against a list of destinations and recommends the destination with the highest match score.

Technologies Used
- Python
- Streamlit
- Visual Studio Code
